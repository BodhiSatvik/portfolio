# AI/ML Professional Portfolio — Satvik Bhasin

Portfolio site for AIML-500 (Machine Learning Fundamentals), Indiana Wesleyan University.

## Deploying to GitHub Pages

1. Create a new public GitHub repo (e.g. `aiml-portfolio`).
2. Push this folder's contents to the repo's `main` branch.
3. In the repo, go to Settings → Pages → set Source to "Deploy from a branch", branch `main`, folder `/ (root)`.
4. Your live site will be at `https://<your-github-username>.github.io/aiml-portfolio/`.
5. Submit that URL for 1.6.
